# 足球比赛全方位分析技能

本技能对足球比赛进行多维度综合分析，结合数学模型、赔率数据、球队基本面、网友意见等，输出专业级比赛预测报告。

## 〇、前置条件 — 信息确认（必须执行）

**如果用户的提问模糊、未提供以下关键信息，必须先通过 `AskUserQuestion` 工具向用户确认，不得直接开始分析。**

### 必须确认的要素：

1. **目标联赛**
   - 五大联赛（英超/西甲/德甲/意甲/法甲）→ 数据丰富，过离散特性不同
   - 次级联赛/杯赛 → 贝叶斯收缩补充，数据量少需谨慎
   - 荷甲/葡超/英冠等 → 过离散突出，负二项必备
   - 不明确则列举当天的焦点比赛让用户指定

2. **具体对阵球队**
   - 必须明确主队和客队名称
   - 支持模糊队名补全（如"曼联"→"Manchester United"）
   - 如用户未指定具体对阵，列举当天可分析的焦点比赛让用户选择

## 一、核心分析维度

分析一场足球比赛时，必须覆盖以下全部维度：

### 1. 数据收集阶段

使用 `WebSearch` 和 `WebFetch` 工具搜索以下数据：

**A. 赔率数据**
- 搜索 `"{主队} vs {客队} 赔率"` 获取欧洲赔率（威廉希尔、bet365、立博等主流公司）
- 搜索 `"{主队} vs {客队} 亚盘 盘口"` 获取亚洲盘口
- 搜索 `"{主队} vs {客队} 竞彩 赔率"` 获取中国体育彩票官方赔率
- 搜索 `"{主队} vs {客队} 大小球"` 获取总进球盘口

**B. 球队基本面**
- 搜索 `"{主队} vs {客队} 伤停"` 获取伤病和停赛信息
- 搜索 `"{主队} 2025 身价 阵容"` 获取球队纸面实力（总身价、核心球员）
- 搜索 `"{主队} vs {客队} 历史交锋"` 获取两队历史对战记录
- 搜索 `"{主队} 近期战绩 2025"` 和 `"{客队} 近期战绩 2025"` 获取近期状态
- **搜索 `"{主队} xG"` 和 `"{客队} xG"` 获取两队的期望进球数据（必须搜索）**
- **搜索 `"{主队} 场均进球 失球 2025"` 和 `"{客队} 场均进球 失球 2025"` 获取进球/失球统计数据**

**★ 数据交叉验证规则（2026-08-08新增，规则37）**
- **每项统计数据必须由≥2个独立来源确认（如Opta + WhoScored，或Transfermarkt + 官方），单源数据禁止直接采用。**
- **数值合理性检查（必做）：** 对输入模型的每个数值做常识校验——如"场均0.4球"在J1这类联赛明显不合理（J1球队场均进球普遍≥1.0），必须触发核查；任何触发直觉怀疑的数值，默认是错的，必须验证后才能使用。
- **禁止编造数据：** 未收集到数据时，字段必须标注"信息缺失"，严禁用推测值或印象值填入模型（如"客队很弱所以填0.4"）。
- **来源留痕：** 标注每项数据的来源URL与获取时间，供回查。
- **数据矛盾处理：** 多来源不一致时，优先权威数据源（Opta/WhoScored/Transfermarkt）＞知名平台（懂球帝/雷速/Fotmob）＞个人分析/自媒体；矛盾无法调和时标注"数据来源矛盾"并采用更保守口径，降低该场置信度。

**C. AI模型与网友意见**
- 搜索 `"{主队} vs {客队} 虎扑 AI 预测"` 或 `"虎扑 足球 AI 分析 {主队} {客队}"` 获取虎扑AI模型结论
- 搜索 `"虎扑 {主队} vs {客队} 赛后"` 或 `"{主队} vs {客队} 虎扑 讨论"` 获取虎扑社区讨论
- 搜索 `"知乎 {主队} vs {客队} 预测"` 获取知乎球迷分析
- 搜索 `"微博 {主队} vs {客队} 预测"` 获取微博球迷意见

### 2. 信息过滤规则

**必须过滤以下内容：**

1. **小编类不可靠建议**：标题带有"小编"、"小编推荐"、"独家内幕"、"稳胆"、"必中"、"带飞"等字样的内容一律标记为不可靠并排除。
2. **假博彩引流贴**：内容中含有不明链接、二维码、微信号、"加群"、"私聊推单"、"包赔"、"充值送彩金"等引流行为的内容一律过滤。
3. **纯情绪化内容**：仅有"冲冲冲"、"干就完了"等无分析实质的水帖标记但不完全排除，仅供情绪参考。
4. **来源评级**：对数据来源标注可靠性等级（A=官方数据/B=知名平台/C=个人分析/D=可疑来源）。

#### 第一类：核心标配模型（行业公认最好用，80% 职业玩家的主力工具）

这是经过几十年市场验证的基准方案，属于必用级别，也是机构赔率定价的底层逻辑。

**（1）Dixon–Coles 修正泊松（DC模型，足彩工业标准）**

```
地位：比分预测的行业金标准，1997年提出至今仍是学术与实战的基准
核心：引入 ρ 参数专门修正 0-0、1-0、0-1、1-1 四类低比分的概率偏差
适用：精确比分、大小球、胜平负全场景，搭配时间衰减权重效果最佳

标准泊松三大硬伤：
1. 低估 0-0、1-1、1-0 等低比分平局
2. 默认主客进球独立
3. 所有历史数据等权

DC模型四大修正：

① 低比分膨胀系数 τ(i,j)：

当 i,j ∈ {0,1} 时：
  P(i:j) = τ(i,j) × P_poisson(i) × P_poisson(j)

  τ(0,0) = 1 + λ_home × λ_away × ρ          （抬高0-0）
  τ(0,1) = 1 - λ_home × ρ                    （压低0-1过高概率）
  τ(1,0) = 1 - λ_away × ρ                    （压低1-0过高概率）
  τ(1,1) = 1 + ρ                              （抬高1-1）

  其中 ρ ∈ [-1,1] 为低进球相关性参数

② 时间衰减权重：
  weight(t) = exp(-ξ × t)
  t = 比赛距今时长（天），ξ = 衰减速率参数（通常 ξ=0.001~0.005）

③ 主客场分离攻防参数：
  不共用攻防参数，主队进攻 vs 客队防守、客队进攻 vs 主队防守独立建模

④ 低进球区间相关性修正：
  引入上述 τ(i,j) 解决 0/1 球区间的联合概率失真

计算步骤：
1. 用 Elo/Pi 评级获取 λ_home, λ_away
2. 应用 DC 修正参数 ρ, ξ
3. 计算修正后的比分概率矩阵
4. 导出主胜/平/客胜概率
```

**（2）泊松回归 / Maher 攻防分离模型**

```
地位：所有进球模型的底层基础框架
核心：将期望进球拆解为「进攻实力 + 对手防守强度 + 主场加成」，可灵活加入协变量

log(λ_home) = α_attack_home - β_defense_away + γ_home_advantage + Σ(δ_i × X_i)

协变量 X_i 包括：
- 核心伤停（-0.15 ~ -0.30 per 核心缺阵）
- 赛程密集度（7天3赛 → -0.10）
- 天气（雨雪 → -0.05 进球期望）
- 球队战意（保级/争冠 → +0.10）
- 历史交锋心理优势（近期3连胜 → +0.05）
- xG 期望进球修正

适用：单联赛稳定建模，新手入门首选
```

---

**（3）负二项分布 Negative Binomial（NB）**

```
地位：过离散联赛的首选泊松替代方案
核心：增加离散参数，适配足球进球 "方差＞均值" 的真实特性
适用：德甲、荷甲等高低分化严重的联赛

泊松要求 方差 = 均值；真实足球 方差 >> 均值

P(X=k) = C(k+r-1, k) × p^r × (1-p)^k

其中：
r = 1/γ （γ 越大 → 离散步长越大）
p = 1/(1 + γ×λ)

实战规则：
1. 计算联赛历史方差/均值比 = VMR
2. VMR > 1.2 → 替换泊松为负二项
3. γ = (VMR - 1) / λ_avg
```

---

**（4）零膨胀泊松 / 零膨胀负二项（ZIP / ZINB）**

```
地位：防守型联赛、低比分赛事的神器
核心：分两阶段建模——

阶段一（逻辑回归）：判断"是否会进球"
  P(goal=0) = φ + (1-φ) × P_poisson(0)     // φ 为零膨胀参数

阶段二（泊松/负二项）：计算"进球数 ≥ 1 时的分布"
  P(goal=k | k>0) = (1-φ) × P_poisson(k)   // 截断后的泊松/负二项

专门解决 0 进球被系统性低估的问题。

适用：意甲、法甲、次级联赛等 0-0 频发的赛事
检测规则：
  联赛 0-0 频率 > 10% → 启用 ZIP/ZINB
  联赛 0-0 频率 > 15% → 必须使用 ZIP/ZINB（意甲标志）
```

---

**（5）Skellam 斯凯拉姆分布（直接预测进球差）**

```
地位：让球盘、胜平负快速计算的最优工具
核心：直接建模「主队进球 − 客队进球」的差值分布

D = 主队进球 - 客队进球

P(D=k) = e^(-(λ₁+λ₂)) × (λ₁/λ₂)^(k/2) × I_k(2√(λ₁λ₂))

其中 I_k(z) 为第一类修正贝塞尔函数

简化计算（k = -N..N）：
P(D=k) ≈ Σ P_home(k+t) × P_away(t)  for t=max(0,-k)..∞

直接输出：主队赢N球、平局、客队赢N球的概率

优势：
- 无需组合所有比分再合并
- 计算胜平负、让球盘效率极高
- 常用于竞彩让球分析

进阶：零膨胀 Skellam（ZI Skellam）
  适用于意甲/杯赛，分两阶段先判断"是否0-0"，再用 Skellam 计算非零进球差
```

**（6）双变量泊松（Bivariate Poisson）**

```
核心：允许主客队进球存在正相关（大开大合的比赛双方同步增多进球）

引入公共 latent 进球参数 λ_c（共同进球因子）

P(主队=k, 客队=j) = Σ P(X1=k-t) × P(X2=j-t) × P(Xc=t)
  for t=0..min(k,j)

其中：
X1 ~ Poisson(λ_home - λ_c)
X2 ~ Poisson(λ_away - λ_c)
Xc ~ Poisson(λ_c)

λ_c 越大 → 两队进球同步性越强（大球/小球一致性高）
λ_c ≈ 0 → 退化为标准泊松

缺点：计算复杂，参数拟合难度高于DC模型
使用规则：DC模型作为主力，双变量泊松作为对比验证
```

**（7）广义泊松分布（Generalized Poisson）**

```
比负二项更灵活，同时支持过离散与欠离散：
  P(X=k) = (λ(λ+k×θ)^(k-1) × e^(-λ-k×θ)) / k!

θ < 0 → 欠离散（极少数极端防守联赛）
θ = 0 → 退化标准泊松
θ > 0 → 过离散（绝大多数足球联赛）

适用：风格极端的小众联赛（如北欧联赛、亚洲联赛）
报告中使用时标注"广义泊松仅供对比参考"
```

**（8）Hurdle 跨栏模型**

```
零膨胀模型的进阶版，两阶段逻辑更贴合足球实际：

阶段一（跨栏）：逻辑回归判断是否破蛋
  P(goal=0) = φ

阶段二（截断分布）：计算进球数 ≥ 1 时的概率
  P(goal=k | k≥1) = P_count(k) / (1 - P_count(0))

与 ZIP 的区别：Hurdle 的零只来自第一阶段（"绝对不进"），
                ZIP 的零可能来自两个阶段（"绝对不进"+"泊松恰好零"）

适用：意甲、法甲、杯赛淘汰赛等 0-0 高风险赛事
```

**（9）Copula 连接函数族（高斯 / Gumbel / Clayton）**

```
机构高阶建模使用，不假设整体线性相关

高斯 Copula：常规联赛的多维进球相关
Clayton Copula：防守联赛的下尾相关（意甲 → 两边都不进球）
Gumbel Copula：大球联赛的上尾相关（荷甲 → 两边一起爆炸性进球）

缺点：计算量大，普通应用极少上手
使用规则：报告中标注"高阶模型仅供对比参考"
```

**（10）有序逻辑回归 / 概率单位回归**

```
胜平负、进球区间预测的经典分类模型

利用"胜 > 平 > 负"的有序特性：
  P(结果 ≤ k) = 1/(1+e^(-(θ_k - Xβ)))

比普通分类模型更贴合足球场景（平局介于胜与负之间），可解释性强

进球区间版本：
  输出 0球 / 1球 / 2球 / 3球 / 4+球 的五分类概率

实际使用：作为赔率校准的辅助判断工具
```

**（11）广义线性混合模型（GLMM）**

```
加入球队随机截距，捕捉球队个体的稳定差异：

log(λ) = fixed_effects + random_intercept_team

优势：
- 适配多联赛、跨赛季的风格差异
- 量化球队"稳定强"或"稳定弱"的内在特质
- 比固定效应模型更鲁棒，不对每支球队单独估计大量参数
```

#### 第三类：赔率校准模型（概率提取的核心，纯统计模型必配）

这是"从赔率中提取真实比赛概率"的关键一步。

**（12）Shin 模型（去抽水校准）**

```
地位：职业玩家标配的赔率真实概率提取工具
核心：基于内幕交易假设，修正庄家"热门少抽水、冷门多抽水"的热门-冷门偏差

Shin 概率提取公式（迭代求解 z）：
  P_i = √(z + (1-z) × (1/o_i)²)   // o_i 为赔率

z 的含义：庄家预估的内幕交易者比例（z通常 0.02~0.05）
z 越大 → 冷门概率向上修正越多

去水后真实概率：
  true_P_i = P_i / Σ P_i

与简单归一化的区别：
- 归一化假设庄家等比例抽水
- Shin假设庄家对热门少抽、对冷门多抽（更符合实际）
- Shin准确度高，是提取真实概率的首选方法

实战规则：
  每次分析必须同时展示 "归一化去水" 和 "Shin去水" 两组结果
  优先使用 Shin 概率作为真实概率基准
```

**（13）Power 去抽水法**

```
通用型校准方案，效果介于归一化和 Shin 之间：

  P_i = (1/o_i)^(1/k)
  k ∈ [0, 1] 为校正系数

k = 1：退化为归一化
k = 0.5~0.7：最接近 Shin 模型效果（推荐默认值）

优势：计算简单，不需迭代，适配大多数常规盘口
```

**（14）Platt 缩放 / 保序回归**

```
模型输出概率的校准工具，修正数学模型的概率偏差：

Platt Scaling：
  P_calibrated = 1 / (1 + e^(A + B × log(P_raw/(1-P_raw))))

保序回归（Isotonic Regression）：
  非参数方法，保证校准后的概率顺序与原始一致

校准方向（基于历史修正经验）：
- 大球概率下修 5-10%（模型通常高估大球）
- 平局概率上修 3-5%（模型通常低估平局）
- 0-0 比分概率上修（ZIP/ZINB 未启用时）

使用规则：
  每张概率表下方必须标注是否已校准、校准方向与幅度
```

**（15）置信度与命中概率评估框架**

```
输出置信度等级所需的全部评估维度：

一、置信度评级体系（基于多维证据综合判断）

A. 模型一致度（权重 40%）
  - 各模型对同一结果的概率是否收敛
  - DC/ZIP/Skellam/蒙特卡洛四者之间的标准差
  - 标准差 < 5% → 模型高度一致 → 置信度+1
  - 标准差 5~10% → 中度分歧 → 置信度不变
  - 标准差 > 10% → 严重分歧 → 置信度-1

B. 赔率对齐度（权重 25%）
  - 加权融合概率 vs Shin 真实概率的差值
  - 差值 < 3% → 模型与市场高度对齐 → 置信度+1
  - 差值 3~8% → 对齐度一般
  - 差值 > 8% → 模型与市场显著偏离 → 置信度-1

C. 数据质量（权重 20%）
  - VMR 检测结论：VMR ≤ 1.2 数据稳定 → +1；VMR > 1.5 过离散严重 → -1
  - 样本量：球队近10场数据完整 → +1；不足5场 → -1
  - 伤停信息明确度：核心伤停已知 → 0；伤停不明确 → -1

D. 外部验证（权重 15%）
  - 网友意见与模型结论一致 → +1
  - 虎扑AI等平台结论与模型结论一致 → +1
  - 历史交锋模式与模型结论一致 → +1

二、命中概率判定

  主胜命中概率 = 加权融合主胜概率 × (1 - VMR修正系数)
  VMR修正系数 = min(0.15, (VMR - 1) × 0.3)

  平局命中概率 = 加权融合平局概率 × 平局膨胀系数
  平局膨胀系数 ∈ [1.03, 1.08]（基于历史平局低估修正）

  客胜命中概率 = 加权融合客胜概率 × (1 - VMR修正系数)

三、置信度等级映射

  综合得分 ≥ 3 → 高置信度 ★★★
  综合得分 1~2 → 中置信度 ★★
  综合得分 0 → 低置信度 ★
  综合得分 < 0 → 极低置信度（观望）

四、命中概率分级

  ≥ 55% → 高概率（强指向性）
  45%~55% → 中概率（有一定倾向）
  35%~45% → 低概率（无明显优势）
  < 35% → 极低概率（高度不确定）
```

**（16）泊松过程 + 生存分析（指数 / 威布尔分布）**

```
滚球大小球的基础模型：

进球视为泊松过程：
  P(在 [t, t+Δt] 内进球) = 1 - e^(-λ_remaining × Δt)

生存分析：
  S(t) = P(距离上次进球 > t) = e^(-λ×t)     ← 指数分布（标准）
  S(t) = e^(-(λ×t)^k)                         ← 威布尔分布（更灵活）

典型场景："70分钟仍 0-0，剩余 20 分钟进球的概率"
  λ_remaining = λ_full × (T_remaining / T_full) × tempo_factor

tempo_factor（比赛节奏系数）：
- 正常节奏：1.0
- 多红牌/频繁犯规中断：0.7~0.8
- 大开大合/大量反击：1.1~1.2
- 一支队背水一战（淘汰赛最后15分钟）：1.2~1.4

实际使用：报告中如需分析半场/滚球场景，运行泊松过程计算
```

**（17）贝叶斯动态状态空间模型**

- 红牌 → 少人方 λ × 0.6，多人方 λ × 1.15
- 核心球员换下 → λ × 0.85
- 核心替补上场 → λ × 1.10

#### 第五类：实力评级体系（所有模型的输入基础）

模型本身只是拟合工具，特征质量决定预测上限，实力评级是最核心的特征来源。

**（19）Elo 评级（基础版）**

```
最通用的实力分系统：

初始分：根据联赛层级设定基础Elo分（英超1500、西甲1450等）

预期得分公式：
  E_A = 1 / (1 + 10^((R_B - R_A) / 400))

赛后更新：
  R'_A = R_A + K × (S_A - E_A)

K值权重：
- 联赛：K = 20
- 杯赛：K = 32
- 友谊赛：K = 8

主场加成：主场Elo + 100

输出：实力差值 → 换算预期进球 λ（喂给进球模型）
```

**（20）Glicko-2 评级（Elo进阶版）**

```
核心改进：增加"评级偏差（RD）"参数

RD 小 → 置信度高（刚打完多场比赛）
RD 大 → 置信度低（久未比赛/休赛期/杯赛中间隔长）

球队久未比赛时：
- 预测区间自动放宽（不确定性增加）
- 赛后更新幅度更大（让数据说话）

适配：休赛期、杯赛场景、间歇期后的首场比赛
使用规则：优先级低于 Pi Rating，作为辅助置信度判断
```

**（21）Pi Rating（足球专用评级，行业首选）**

```
核心：内置攻防分离参数、xG校正、时间衰减

进攻分 Pi_att = 基于 xG 的进攻效率评分
防守分 Pi_def = 基于 xGA 的防守效率评分
综合分 Pi = Pi_att - Pi_def

主场球队预期进球 λ_home = league_avg × exp(Pi_att_home - Pi_def_away)
客场球队预期进球 λ_away = league_avg × exp(Pi_att_away - Pi_def_home)

优势：攻防独立建模，比Elo更精细刻画进球数
```

**（22）xG 期望进球模型（★ 每场必用的核心特征工程工具）**

```
★ 必用原因：xG 是当前足球分析中最核心的特征来源，决定了 λ 校准的准确性

xG 分拆维度：
- 射门距离（禁区内/外）
- 射门角度（正对球门/小角度）
- 防守人数（无防守/1人/多人）
- 射门方式（头球/左脚/右脚、定位球/运动战）
- 是否单刀、是否反击
- 机器学习计算单次射门得分概率

单场 xG = Σ 每次射门的 xG 值

用途：
- 修正"射门多但不进球"的运气干扰
- 大幅提升 λ 准确度
- 检验球队真实状态（xG与实际进球偏离大 → 状态不可持续，回归均值概率高）
```

**（23）TrueSkill 团队评级**

```
微软开发的团队对抗评级系统：

优势：
- 输出 μ（均值评分）和 σ（不确定度）两个参数
- 跨联赛对比能力强（不受联赛层级限制）
- 天然支持多人团队（球星转会不影响体系）

实际使用：

**（24）分层贝叶斯攻防模型**

```

**（33）多模型方差分析**

```
量化各模型之间的一致性程度：

模型对同一结果的概率标准差：
  σ_result = std(P_DC, P_NB, P_ZIP, P_Skellam, P_MC)

σ 越小 → 模型间越一致 → 置信度越高

一致性等级：
  σ < 0.03 → 高度一致（置信度显著提升）
  σ 0.03~0.06 → 中度一致
  σ 0.06~0.10 → 轻度分歧（需警惕）

输出格式：
  模型间标准差：{σ_主胜, σ_平局, σ_客胜}
  一致性等级：{高度一致 / 中度一致 / 轻度分歧 / 严重分歧}
```

### 4. 过离散检测与零膨胀判断

**过离散检测规则：**

```
VMR = 联赛历史进球方差 / 联赛历史场均进球

VMR ≤ 1.05 → 标准泊松可用
VMR 1.05~1.2 → DC模型
VMR > 1.2 → 负二项分布替换泊松（必须）
VMR > 1.5 → 同时使用负二项 + 广义泊松对比（德甲/荷甲标志）

检测代码（伪代码）：
league_goals = [每场比赛总进球数 for recent_N_matches]
vmr = variance(league_goals) / mean(league_goals)
if vmr > 1.2:
    use_negative_binomial = True
```

**零膨胀检测规则：**

```
league_00_rate = 联赛 0-0 比赛数 / 总比赛数

league_00_rate < 5% → 不需要零膨胀
league_00_rate 5%~10% → ZIP/ZINB 可选
league_00_rate 10%~15% → 推荐启用 ZIP/ZINB
league_00_rate > 15% → 必须启用 ZIP/ZINB + Hurdle 对比（意甲标志）
```

### 5. 模型选择与组合策略

**主力模型架构（按优先级）：**

```
Layer 0 — 联赛诊断：
  VMR 过离散检测 + 零膨胀检测 → 决定使用哪套分布

Layer 1 — 实力评级输入 + xG 校准：
  ★ 必用：Elo 实力分 + Pi Rating + xG 期望进球数据
  辅助：Glicko-2(置信度参考) + TrueSkill(跨联赛)
  → 用 xG 校准 λ_home, λ_away 基准
  → xG 实际值 vs 预期值的偏离幅度作为状态修正系数输入

Layer 2 — 进球分布模型：
  ★ 必算：Dixon–Coles 修正泊松（基于泊松分布的主力模型，每场必算）
  过离散联赛（VMR > 1.2）：负二项分布替换标准泊松（DC修正框架保留）
  0-0 联赛（利率 > 10%）：ZIP/ZINB 叠加
  对比验证：双变量泊松
  → 所有分析中泊松分布族（DC/Poisson/NB/ZIP）必须至少启用一个

Layer 3 — 进球差模型（辅助）：
  Skellam 分布 → 直接计算胜负球差概率
  用于竞彩让球分析
  0-0 联赛叠加 ZI Skellam

Layer 4 — 特征修正（★ 必做）：
  xG 校准修正：用收集到的 xG 数据动态校准 λ_home / λ_away
    公式：λ_修正 = λ_原始 × (xG_实际 / xG_预期)
    若 xG 实际值长期偏离预期值，说明球队状态不可持续，需做均值回归修正
  泊松回归协变量修正：伤停/赛程/天气/战意动态调整 λ

Layer 5 — 赔率校准：
  Shin 模型（主要） + Power 去抽水（对比）
  → 提取无偏真实概率

Layer 6 — 模拟与校准：
  蒙特卡洛 10000 场模拟 + 多模型方差分析
  Platt 缩放 / 保序回归校准概率

Layer 7 — 综合判决：
  加权融合各模型结果：
  - DC模型/负二项/ZIP 概率 35%
  - Skellam概率 15%
  - Elo/Pi评级概率 15%
  - Shin校准概率 15%
  - 网友意见 10%
  - 虎扑AI 5%
  - 有序逻辑回归校准 5%
  
  → 输出置信度评级 + 命中概率
```

### 7. 隐含赔率与概率提取

**隐含概率（Implied Probability）：**

```
隐含概率 = 1 / 欧洲赔率
```

**简单归一化去水：**

```
总隐含概率 = 1/主胜赔率 + 1/平局赔率 + 1/客胜赔率
真实主胜概率 = (1/主胜赔率) / 总隐含概率
真实平局概率 = (1/平局赔率) / 总隐含概率
真实客胜概率 = (1/客胜赔率) / 总隐含概率
抽水率 = 总隐含概率 - 1
```

**Shin 模型去水（首选）：**

```
迭代求解 z（内幕交易者比例）：
  minimize |Σ √(z + (1-z) × (1/o_i)²) - 1|

Shin真实概率：
  P_i = √(z + (1-z) × (1/o_i)²) / Σ √(z + (1-z) × (1/o_j)²)

z 越大 → 冷门概率向上修正越多
```

**概率差（模型 vs 市场）：**

```
概率差 = 加权融合概率 - Shin真实概率

概率差 > 5% → 模型显著看好该结果（可作为高置信度信号之一）
概率差 2%~5% → 模型略微看好
概率差 -2%~2% → 模型与市场一致
概率差 < -2% → 模型低于市场预期
```

### 8. 半全场胜平负预测

```
半全场组合 = {胜胜, 胜平, 胜负, 平胜, 平平, 平负, 负胜, 负平, 负负}

预测方法：
1. 上半场 λ_half_home = λ_home × 上半场占比系数
   - 高压球队（前15分钟进球率高）：系数 0.45~0.50
   - 慢热球队（下半场发力）：系数 0.35~0.40
   - 默认：系数 0.42
2. 上半场 λ_half_away = λ_away × 上半场占比系数
3. DC 模型计算上半场比分概率
4. 下半场 λ = (全场λ) - (上半场λ)
5. 组合得到半全场 9 种结果的概率
6. 用蒙特卡洛验证并输出 Top 3

给出最可能的半全场结果（Top 3 及概率）
```

### 9. 总进球数预测

```
总进球数 λ_total = λ_home + λ_away

标准泊松（参考）：
  P(总进球数 = k) = (λ_total^k × e^(-λ_total)) / k!

负二项（过离散联赛）：
  P(总进球数 = k) = C(k+r-1, k) × p^r × (1-p)^k

ZIP/ZINB（0-0联赛）：
  P(k=0) = φ + (1-φ) × P_base(0)
  P(k>0) = (1-φ) × P_base(k)

蒙特卡洛复核：
  模拟 10000 场比赛的总进球分布

给出：0球、1球、2球、3球、4+球的概率分布
结合大小球盘口（如 2.5球）给出大球/小球概率
标注过离散调整幅度和零膨胀修正
```

## 四、关键注意事项

1. **前置条件检查：** 用户提问模糊时必须先确认目标联赛、具体球队，不得跳过。
2. **赔率数据时效性：** 优先使用最新赔率，标注数据获取时间
3. **Shin 去水优先：** 报告必须同时展示归一化去水和 Shin 去水两组结果，Shin 概率作为真实概率基准
4. **模型局限性声明：**
   - DC模型虽为行业标准，仍假设进球事件独立（修正了0/1球区间，但无法完全解决）
   - 负二项/ZIP 校正可减少误差，但无法消除
   - 贝叶斯收缩适用于小样本，但对顶级豪门意义有限
   - 所有模型均基于历史数据，突发因素无法预测
5. **VMR + 零膨胀检测必须执行：** 每次分析必须计算联赛方差/均值比和 0-0 频率，决定主力分布
6. **蒙特卡洛必须运行：** 每次分析必须运行 10000 场模拟，不可跳过
7. **模型对比展示：** 报告中必须至少展示 DC、NB/ZIP、Skellam、蒙特卡洛四组结果
8. **xG 数据必须采集与校准：** 每次分析必须搜索并引用两队近10场的 xG 数据（实际进球 vs 期望进球），用 xG 校准 λ_home / λ_away，在报告中展示 xG 校准前后的 λ 对比
9. **泊松分布族必用：** 每次分析必须使用至少一种基于泊松分布的模型（DC/Poisson/NB/ZIP）。DC（Dixon-Coles 修正泊松）为首选主力模型，仅在过离散严重时替换为负二项
10. **置信度评级必配：** 每次分析必须输出置信度评级（高/中/低/极低）及评级依据
