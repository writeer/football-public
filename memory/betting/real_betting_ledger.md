## 三、口径说明

- **本台账 = 真实现金投注口径**，只记录真金白银的投入、回收与净额。
- `memory/trials/score_parlay_trial.md` / `.json` = **模型试用台账**，只统计比分方向与精确命中率（exact/semi/miss），**不含任何资金字段**。
- `memory/backtests/**`、`reports/backtest/**` 中的“投入 N 单位 / 回收 X 单位 / ROI”= **模型回测模拟口径**，用于检验策略，**不是真实现金**。
- 真实亏损**只记入本台账**，不得回填到模型回测或试用台账；两套口径分别累计、互不混用。
