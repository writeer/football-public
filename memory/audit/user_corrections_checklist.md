# 用户纠正回写清单（审核固定项）

> 用途：把历史上用户当场纠正过的问题，固化为每次审核必查的固定项。审核清单必须逐条引用本表编号（U1、U2…），并给出机械证据。
> 维护：每次用户提出新纠正 → 追加一行 → 同步在当次审核清单中新增对应检查项。

## 使用方式

1. 审核清单开头的"〇、口径与来源"必须列出 U1-U6 的引用状态。
2. 上报结论只能引用脚本输出，不得复述"应该没问题"。
3. 新增纠正时，本表编号顺延（U7、U8…），不得重排旧编号。
