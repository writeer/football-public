# 篮球「净胜分众数双轨制」— 试用期登记台账

> **对应逻辑**：`AGENTS.md` 规则52a（让分首选＝无条件净胜分众数）＋ 规则67（比分/档位双轨制：`k_dist` 记录 + `k_rec` 推荐）
> **迁移说明**：足球端锚点是「净胜球」，篮球端锚点为「净胜分」；玩法映射为 —— 足球胜平负→篮球`胜负`、让球→`让分胜负`、比分→`胜分差`（6档×2侧）、总进球→`大小分`。
> **试用起算日**：2026-09-21（篮球首期）
> **转正条件**：累计 **≥20 场** 且 **胜分差档位命中率 ≥60%** → 升级为「篮球必备档位流程」，写入串关优化器强制步骤
> **命中判定**：档位精确命中（实际净胜分落入 `k_rec` 所在档）＝**命中**；方向命中但档位不同＝**半命中**（不计入命中率分子）；方向未中＝**未命中**
> **登记责任人**：总控（每次使用后逐场登记，漏登视为本场不计入统计）
> **注意**：本台账与足球端 `score_parlay_trial.md` **相互独立、不得互相污染**；足球端待裁决项（口径A/口径B）不影响本台账。

3. 302/305 为"压线场"（模型净胜分与让分线相差 ≤1.5 分），让分命中天然接近 50%，可作为后续"压线场不宜重注"的样本来源。
