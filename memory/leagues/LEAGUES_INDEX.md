## 二、数据维度说明

每个联赛JSON文件包含以下维度：

### 1. league_info（联赛基础信息）
- 联赛全称、英文名、国家、级别、球队数量、赛制
- 赛季时间、是否跨年
- 竞彩开售状态

### 2. statistics（基础统计）
- 场均进球、平局率、主客场胜率
- 大小球OVER/UNDER 2.5比例
- 最常见比分TOP5
- 总进球分布
- **半场平局率 ht_draw_rate**（规则66，2026-09-12全联赛补录，见下方专节）

### 3. match_style（比赛风格）
- 战术风格特点
- 比赛节奏、对抗强度
- VAR使用情况

### 4. referee_and_stoppage（裁判与伤停补时）
- 裁判执法风格
- 场均黄牌/红牌/点球
- 伤停补时规律

### 5. integrity_and_discipline（官方文件与假赛）
- 历史假赛记录
- 官方纪律处罚特点
- 官方规则文件

### 6. public_opinion_and_market（网友评价与市场特点）
- 网友/彩民评价
- 博彩市场特点
- 冷门频率
- 竞彩注意事项

### 7. data_sources（数据来源）
- 数据来源链接
- 更新时间

## 三、使用方式

```python
import json
from pathlib import Path

# 加载单个联赛数据
league_path = Path("memory/leagues/premier_league_en.json")
with open(league_path, "r", encoding="utf-8") as f:
    league_data = json.load(f)

# 获取联赛场均进球
avg_goals = league_data["statistics"]["avg_goals_per_match"]
```

## 五、半场平局率 ht_draw_rate（规则66专用，2026-09-12补录）

> **口径**：半场结束时比分为平局（0-0/1-1/2-2…）的场次 ÷ 总场次。
> **数据源**：① football-data.co.uk 官方逐场半场比分(HTHG/HTAG)，16个欧洲联赛各取5季合并（1188-2760场）；② thefishy.uk "(Halves) 1st Half" 半场积分表（ΣD/ΣP）。两源在 意甲/德甲/法甲/西甲/荷甲/葡超 6 个联赛**数值一致到小数点后四位**，互为验证。
> **字段**：`ht_draw_rate` / `ht_draw_rate_note` / `ht_draw_rate_source` / `ht_draw_rate_updated` / `ht_draw_rate_tier` / `ht_draw_rate_confidence` / `ht_draw_rate_status`

## 六、使用方式（半场平局率）
