## 调取协议（AGENT必读）

### 第1步：提取当前场次关键词
从待分析的每场比赛中提取以下维度关键词：
- **联赛/赛事**：如"荷甲"、"欧联"、"解放者杯"、"韩职"
- **赛事类型**：如"联赛"、"杯赛首回合"、"杯赛次回合"、"淘汰赛"
- **赛事阶段**：如"新赛季首轮"、"揭幕战"、"末轮"
- **球队特征**：如"保级队"、"争冠队"、"升班马"、"铁桶阵"、"大热"
- **伤停情况**：如"后防危机"、"残阵"、"核心缺阵"、"双方≥5人"
- **特殊场景**：如"补时绝平风险"、"大幅轮换"、"平局高发轮次"

### 第2步：标签匹配（三级匹配）
将关键词与下方「关键教训速查表」的标签列匹配：
- **强匹配**（必读）：相同联赛 + 相同赛事类型，或相同特殊场景标签直接命中
- **中匹配**（推荐读）：相同联赛或相同赛事类型，或相同球队特征
- **弱匹配**（可选读）：相同伤停情况或相同规则编号

### 第3步：选取最近5条强相关记录
1. 先取所有**强匹配**记录，按日期倒序排列
2. 若强匹配不足5条，用**中匹配**补足至5条
3. 若仍不足5条，用**弱匹配**补足
4. 最多读取5条记录对应的教训文件
5. 在Notes中标注引用了哪些教训ID（如"引用L003/L007/L012"）

### 第4步：应用于分析
匹配到的教训必须体现在当前分析中：
- **模型修正**：如lambda上修/下修、平局概率上修、半全场路径权重调整
- **推荐修正**：如让球独立评估、次选概率上修、TTG与比分一致性校验
- **置信度调整**：如杯赛首回合降一级、残阵降级
- **串关选场**：如平局高发轮次让球串优先、半全场串避免同类型风险
