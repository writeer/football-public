# 推特发文模板

> **触发条件**：用户要求"推特报告转换"/"推特简报"/"发推特"时使用本模板
>
> **输出文件命名**：`{date}_{day}_twitter.md`，保存至 `reports/analysis/` 目录
>
> **数据来源**：从对应的预测JSON或知乎分析报告中提取结论数据

---

## 模板正文

```
⚡ {星期}体彩速报 | {日期}

🏟 赛事介绍：{联赛A描述}{场次数}场 {emoji} + {联赛B描述}{场次数}场 {emoji} + {联赛C描述}{场次数}场 {emoji}

🔑 表情说明：{联赛emoji映射} | 🏠主胜 🤝平局 ✈️客胜 | ⚽总进球 🎯比分

📌 逐场预测：

{联赛emoji} {编号} {主队} vs {客队}（{联赛简称}）
{方向emoji} 首选{首选方向}{首选概率}% / {次选emoji} 次选{次选方向}{次选概率}%
⚽ 总进球：{进球首选} / {进球次选}
🎯 比分：{比分1} > {比分2} > {比分3}

（以上逐场块按编号顺序重复）

{hashtags}
```

---

## 填充规则

### 1. 标题行
- `{星期}`：周几，如"周四"
- `{日期}`：比赛日日期，如"8月14日"

### 2. 赛事介绍行
- 按联赛分组统计场次数
- 每个联赛后加对应emoji
- 联赛之间用 ` + ` 连接

### 3. 表情说明行
- 联赛emoji映射放在最前，用空格分隔
- 方向emoji固定：🏠主胜 🤝平局 ✈️客胜
- 数据emoji固定：⚽总进球 🎯比分

### 4. 联赛emoji对照表

| 联赛 | emoji | 说明 |
|:---|:---|:---|
| 沙特联 | 🟡 | 黄色圆 |
| 欧联（主场优势型） | 🔴 | 红色圆 |
| 欧联（客场优势型） | 🔵 | 蓝色圆 |
| 解放者杯 | 🌎 | 地球 |
| 欧冠 | ⭐ | 星 |
| 英超 | 🦁 | 狮 |
| 西甲 | 🐂 | 牛 |
| 德甲 | 🥨 | 椒盐卷饼 |
| 意甲 | 🍕 | 披萨 |
| 法甲 | 🐓 | 公鸡 |
| 日职 | 🌸 | 樱花 |
| 韩职 | 🏯 | 城堡 |
| 其他联赛 | ⚽ | 足球 |

> 说明：欧联场次根据比赛性质选🔴或🔵，无特殊偏好时默认🔴

### 5. 逐场块填充

每场比赛4行，格式固定：

**第1行 - 场次标题**：
```
{联赛emoji} {编号} {主队} vs {客队}（{联赛简称}）
```

**第2行 - 胜平负方向**：
```
{首选方向emoji} 首选{首选方向}{首选概率}% / {次选方向emoji} 次选{次选方向}{次选概率}%
```
- 首选/次选方向emoji根据方向选择：🏠主胜 / 🤝平局 / ✈️客胜
- 概率保留1位小数

**第3行 - 总进球**：
```
⚽ 总进球：{首选进球数} / {次选进球数}
```
- 仅输出TOP2，不输出备选

**第4行 - 比分**：
```
🎯 比分：{比分1} > {比分2} > {比分3}
```
- 输出TOP3比分，用 ` > ` 连接

### 6. Hashtags
- 以 `#` 开头，空格分隔
- 默认包含：`#竞彩`
- 按本场赛事涉及的联赛添加，如 `#欧联杯` `#解放者杯` `#沙特联`
- 联赛hashtag对照：沙特联→#沙特联，欧联→#欧联杯，欧冠→#欧冠，解放者杯→#解放者杯，英超→#英超，等

## 完整示例

```
⚡ 周四10场体彩速报 | 8月14日

🏟 赛事介绍：沙特职业联赛揭幕战2场 ⚽ + 欧罗巴联赛Q3次回合6场 🇪🇺 + 南美解放者杯1/8决赛首回合2场 🌎

🔑 表情说明：🟡沙特联 🔴欧联 🔵欧联 🌎解放者杯 | 🏠主胜 🤝平局 ✈️客胜 | ⚽总进球 🎯比分

📌 逐场预测：

🟡 001 艾卜哈 vs 拉斯决心（沙特联）
🏠 首选主胜37.8% / 🤝 次选平局31.3%
⚽ 总进球：2球 / 4+球
🎯 比分：1:1 > 0:0 > 1:0

🔴 002 克拉约瓦大学 vs 库奥皮奥（欧联Q3）
🏠 首选主胜61.7% / 🤝 次选平局25.2%
⚽ 总进球：2球 / 4+球
🎯 比分：1:0 > 2:0 > 1:1

（...后续场次按相同格式...）

#竞彩 #欧联杯 #解放者杯 #沙特联
```

## 注意事项

1. **不带赔率**：推特简报不输出任何赔率数值
2. **不推荐串关**：不输出串关推荐内容
3. **表情必须一致**：严格使用表情说明行中定义的表情对照
4. **逐场格式固定**：每场4行，不多不少
5. **比分用 ` > ` 连接**：不用逗号或顿号
6. **概率保留1位小数**：如37.8%
