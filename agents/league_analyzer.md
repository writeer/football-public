# 子Agent：联赛分析器 | League Analyzer

> **触发时机：** 确定比赛联赛后立即执行，在模型计算之前；**跨联赛赛事（欧冠/欧联/亚冠/解放者杯等）先执行规则76等级差判定，再进入常规联赛分析**
> **输入：** 联赛名称、主客队名称、赛事类型（联赛/杯赛/资格赛）
> **输出：** 联赛特点数据、联赛特定修正系数、比分先验、TTG修正、**跨联赛等级差判定与校准建议（规则76）**、**欧冠联赛阶段强弱/豪门对局大球档位建议**
> **包含规则：** 规则22（韩职特化 + 9联赛特化：EPL/SPL/ALL/SA/L2/LL/POR/BRA/L1）、规则24、规则30、规则31、规则34（含欧冠联赛阶段大球修正）、规则35、规则57、规则66、规则76

---

## 任务说明

不同联赛的进球分布、平局率、主场优势差异巨大。本子Agent负责加载联赛特点数据，执行联赛特定修正，包括lambda基准修正、平局概率修正、比分先验、TTG修正等。

## 规则22：韩职联赛特化分析

### 主场优势特化
- 韩职主场加成从默认1.12→**1.20**
- 保级/争冠战意加成：主场队有保级或争冠战意时，lambda额外+0.15
- 军旅球队（金泉尚武）主场lambda额外+0.10

### 战意分析（必做）
- 保级队主场（排名后4位）：平局+8%，主胜+5%
- 争冠队客场（排名前3）客场攻击力<1.0时lambda×0.90
- 近3客场不胜→客胜下修-10%

### 市场热度反向指标
- 市场支持率>70%的一方：必须触发冷门检查，平局+5%，反向+3%
- **市场热度仅作反向参考，不作为正向推荐依据**

### 平局权重特化
- 韩职整体平局率约28-32%
- 0:0/1:1/2:2概率上修+5%
- 赛季平局率>45%的球队，平局概率额外上修+10%

### 冷门检测清单（每场韩职必查）
1. ☐ 主场队是否为保级/争冠战意？
2. ☐ 市场支持率是否>70%？
3. ☐ 客队近期客场状态如何？
4. ☐ 主场队赛季平局率>45%？
5. ☐ 是否为军旅球队主场？

### 韩职分析优先级
```
数据面(进球/失球/xG) > 新闻面(战意/伤停) > 主场优势 > 历史交锋 > 市场热度（仅反向参考）
```

## 规则22-EPL：英超联赛特化分析（2026-08-24新增；**2026-09-13强化——主场加成低 / 无弱旅 / 按最近状态上修弱队系数**）

### 核心认知（2026-09-13强化，用户连续多日实战观察）
- 英超赔率与实力高度正相关，Big6 vs 弱队的赔率能较好反映实力差距
- **英超主场加成显著低于其他联赛**——"主场优势"被实力差与状态差大幅抵消
- **英超无真正弱旅**：中下游球队普遍具备高强度对抗与成型战术，**只要近期状态好，爆冷强队是常态而非例外**
- **Big6内战市场效率最高**——强队之间赔率反应灵敏，信息已充分反映
- **决定性变量是"最近状态"，不是"主场身份"**：弱队状态好即上修弱队系数，强队状态差即下修强队系数

### 实证数据（项目内部回测样本，2026-09-13统计）

| 指标 | 英超 | 说明 |
|:---|:---:|:---|
| 样本量 | 24场 | 来源：`memory/backtests` 历史归档去重统计 |
| 主胜 | 7场（**29.2%**） | 处于样本联赛低位 |
| 平局 | 8场（33.3%） | 高于常态 |
| 客胜 | 9场（**37.5%**） | **客场胜率反超主场**（样本中唯一） |

- 对照样本：西甲主胜50.0%、德甲62.5%、日职55.6%、意甲33.3%、瑞超43.3%——英超主胜率明显偏低
- 单轮极端案例（2026-09-12 英超7场）：**主胜0场**、平4场（012切尔西2-2赫尔城、013伯恩茅斯2-2布伦特福德、016利物浦0-0富勒姆、022热刺0-0埃弗顿）、客胜3场（014维拉1-2诺丁汉、015水晶宫2-3伊普斯维奇为**弱队客场爆冷**；029桑德兰0-2阿森纳为强队客胜）
- **样本量提示**：24场/7场样本偏小，结论按"方向性证据"执行；**后续每轮回测须更新本表**，若主胜率回升至40%以上须重新评估下调幅度

### 主场优势下调（英超专属）
- 主场系数基准：**1.18 → 1.10-1.13**
- 主胜概率：**下修 -3~-5%**
- 平局概率：**上修 +4~6%**
- 客胜概率：相应上修（不因客场身份额外下修）

### 弱队状态系数上修（英超核心机制，替代原"主场爆冷"逻辑）
**状态判定口径（近5轮）**：近5轮积分≥7分 或 近3轮≥2胜 = **状态好**；近5轮积分≤3分 或 近3轮≤1胜 = **状态差**。

| 情形 | 修正 |
|:---|:---|
| 弱队（非Big6）状态好 | 该队攻击λ **+10~20%**；其胜/平概率上修 |
| 强队（Big6）状态差 | 该队攻击λ **-10~15%**、防守λ上修；被爆冷概率上修 |
| 两者同时成立 | 弱队上修取下限+20%，**爆冷概率上修幅度加倍** |
| 弱队状态好 + 客场 | **不因客场身份下修**（英超客场不构成劣势） |
| 状态数据缺失 | 降级为"不修正"，报告标注信息缺失；**不得用主客场身份代替状态判断** |

### 爆冷预警（英超每场必查，2026-09-13新增）
- 触发：**"强队近3轮≤1胜" 或 "弱队近5轮≥7分" 任一成立** → 标注**英超爆冷预警**
- 预警场次：**方向次选必须覆盖平局与爆冷方向**（不得只给强队方向的"胜/平"）
- 置信度：预警场次**降一级**（★★★→★★、★★→★）

### Big6内战处理
- Big6之间的比赛：不额外修正方向概率（市场效率高，赔率已反映实力）
- 重点关注战意/伤停/赛程等基本面因素（规则28基本面决定论）
- 进球预期适度下调（双方防守质量高，Big6内战通常2-3球）

### 圣诞快车期修正（12月20日-1月5日左右）
- 密集赛程（3天一场）导致轮换和体能问题极大
- 所有场次平局概率上修+3%
- 下狗（排名低的一方）爆冷概率上修+5%
- 大球率适度下调（体能下降→进攻效率降低）

### 升班马修正（2026-09-13修订）
- 升班马**仅在新赛季前6轮**享主场加成+3%（主场氛围+拼劲）
- **第7轮起改按"最近状态"判定**，不再无条件给主场加成（无弱旅逻辑同样适用于升班马）
- 升班马vs Big6：不额外修正（实力差距过大）；但若升班马近5轮≥7分，仍适用弱队状态上修

### 英超分析优先级（2026-09-13修订）
```
最近状态(近5轮积分/近3轮胜负) > 伤停/战意/赛程 > 数学模型 > 市场赔率(效率高但低估弱队状态) > 历史交锋 > 主客场身份
```

### 与其他规则的关系
- **与规则65（大球上修）**：英超仍为 Tier1 例外、**不上修大球**（防守严密）；但英超爆冷预警引发的平局上修与规则65无关，二者独立作用
- **与规则68（总控强制走查）**：总控对每场英超场次走查"弱队近5轮状态/强队近3轮状态"，触发即强制上修，不依赖自觉
- **与规则66（半场平局）**：英超 ht_draw_rate 32.5%（中低档），半场参数标准不修正
- **与规则22-L1（法甲）**：同为"实力差距被高估"的联赛，但机制不同——英超是"无弱旅＋状态驱动"，法甲是"除PSG外水平接近＋平局上修"

## 规则22-SPL：沙特职业联赛特化分析（2026-08-24新增）

### 核心认知
- 三强（利雅得胜利、利雅得新月、吉达联合）垄断，两极分化极其严重
- **球星效应是沙职第一变量**——核心巨星伤停对球队实力影响远超普通联赛
- **弱队主场有爆冷能力**——主场优势极高(1.20) + 弱队主场战意强

### 球星伤停放大修正
当三强球队的核心巨星（C罗、本泽马、内马尔等级别）缺阵时：
- 该队进攻lambda下修幅度比普通联赛**放大50%**（普通联赛核心射手缺阵下修15%→沙职下修22-25%）
- 原因：沙职球队进攻高度依赖球星个人能力，体系化程度低于五大联赛
- 必须确认首发名单后再做最终判断（赛前1小时首发是唯一可靠信源）

### 弱队主场加强修正
当非三强球队主场作战时：
- 主场优势系数从基准1.20上调至**1.28**
- 主胜概率上修+4%
- 三强客场对阵非三强时，客胜概率下修-5%
- 警惕弱队主场"拼命+主场哨+天气适应"三重加成

### 利雅得德比特化
- 利雅得胜利 vs 利雅得新月：进球预期上修+15%
- 大球率显著提升，比分TOP5应以2-1、3-1、2-2、3-2为主
- 双方战意拉满，不建议博平局

### 三强vs弱队让球修正
- 三强主场让2球及以上时，让胜概率下修-8%（弱队铁桶+偶尔爆冷）
- 三强客场让1球时，让胜概率下修-5%（客场不稳+弱队主场加成）

### 沙职分析优先级
```
球星伤停/首发确认 > 三强/非三强身份判定 > 主客场 > 战意 > 历史交锋 > 市场赔率
```

## 规则22-ALL：瑞典超级联赛特化分析（2026-08-24新增）

### 核心认知
- 三强（马尔默、佐加顿斯、哈马比）主场极强势，客场不稳
- 夏季联赛（4-11月），夏歇期前后状态波动大
- 北欧主场优势高于五大联赛平均水平

### 三强主场特化
三强球队主场作战时：
- 主场lambda额外+0.15
- 主胜概率上修+5%
- 马尔默主场加成最大，佐加顿斯次之，哈马比第三

### 三强客场不稳修正
三强球队客场作战时：
- 客场攻击力lambda×0.92（下修8%）
- 客胜概率下修-5%
- 平局概率上修+3%
- 原因：北欧球队客场旅行+客场氛围影响，三强客场统治力远不如主场

### 夏歇期前后修正
- 夏歇前最后2轮：强队战意可能松懈，爆冷率上升，下狗+4%
- 夏歇后前2轮：状态不稳定，平局概率上修+3%
- 夏歇期通常在6-7月间，具体日期以当赛季为准

### 赛季末保级修正
- 赛季末（第25-30轮）保级队主场：主胜+5%，平局+3%
- 保级队主场战意极强，北欧球队主场+保级双重buff

### 瑞超分析优先级
```
主客场（三强主场/三强客场） > 联赛阶段（夏歇/保级） > 伤停/状态 > 历史交锋 > 市场赔率
```

## 规则22-SA：意甲联赛特化分析（2026-08-24新增）

### 核心认知
- 意甲平局率五大联赛偏高(27.3%)，防守足球传统深厚
- 三强（尤文图斯、国际米兰、AC米兰）格局相对稳定
- 中下游球队防守严密，大球难出
- 保级队末轮经常爆冷，战意极强

### 平局基准上修
- 意甲所有场次平局概率基准上修+3%
- 中下游球队之间的对决：平局额外上修+2%（合计+5%）
- 1-1和1-0比分概率额外×1.10（意甲最常见比分）

### 三强重点关注
三强（尤文/国米/米兰）比赛需特别注意：
- 三强主场：主胜概率上修+3%（意甲主场+三强双重加成）
- 三强客场：需警惕平局（意甲客场难打+防守好），平局+3%
- 三强内战：进球预期下调，平局概率上修+4%（双方防守质量高）
- 三强vs保级队客场：保级队战意极强，主胜+4%，平局+3%

### 中下游小球修正
- 中下游球队之间的比赛：大球率下调，UNDER 2.5概率上修+5%
- lambda_total下修-0.2（防守大战，进球少）
- 0-0/1-0/1-1比分概率×1.15

### 保级战特化（赛季末）
- 保级队主场vs中游队：主胜+6%，平局+4%
- 保级队之间的6分战：平局概率上修+5%（双方都输不起）
- 赛季末（第30轮后）保级相关比赛强制触发冷门检查

### 意甲分析优先级
```
防守/战术 > 平局基准 > 三强身份 > 保级战意 > 主客场 > 历史交锋 > 市场赔率
```

## 规则35：总进球数联赛特定分析

### 修正方法
1. 加载联赛JSON → 提取场均进球、大2.5球率、实际进球分布
2. 计算联赛平均lambda下的泊松分布
3. 计算实际分布与泊松分布的比值（修正比）= actual / poisson
4. 修正比截断在 [0.50, 2.50]
5. 对比赛特定泊松分布施加 dampened 修正（保留55%原始模型 + 45%联赛特征）
6. 归一化后得到修正后的TTG概率分布

### 技术参数
- dampening = 0.45
- 修正比截断 = [0.50, 2.50]
- 数据源 = `memory/leagues/`

### 新赛季修正条款（2026-08-15新增，来源L013）

新赛季前2轮的lambda_total基准额外+0.3-0.5。

> 来源：2026-08-14回测，17场中10场≥4球(59%)，远超泊松分布预期。模型lambda普遍集中在2.34-2.95区间(对应2-3球)，严重低估新赛季第2轮进球倾向。原因：各队磨合期防守不稳 + 高温影响防守端体能 + 多场出现点球等系统性因素叠加。

修正规则：
1. 新赛季第1-2轮 → lambda_total额外+0.3-0.5
2. 新赛季第3-4轮 → lambda_total额外+0.1-0.2（递减）
3. 第5轮起 → 回归联赛基准lambda，不再额外修正
4. 叠加联赛JSON修正后，取两者中较高者（避免双重下修抵消）

## 规则57：乙级联赛风险修正（2026-08-15新增，来源L015回测教训）

### 适用范围
所有第二级别联赛：德乙(2. Bundesliga)、荷乙(Eerste Divisie)、法乙(Ligue 2)、英冠(EFL Championship)、日乙(J2)等。

### 核心问题
乙级联赛具有以下系统性风险：
1. **阵容变动大** — 升降级导致人员流动远超顶级联赛，新赛季数据参考价值极低
2. **赛季初冷门高发** — 德乙JSON已标注"赛季初1-10轮冷门高发，降级队首轮胜率仅约40%"
3. **平局被系统性低估** — 2026-08-14回测8场乙级联赛中3场平局全部未在首选/次选中，实际平局率37.5%远超联赛历史23-28%
4. **数据质量低** — 二级联赛信源少，伤停/阵容信息更难获取
5. **战意不对称** — 荷乙阶段赛制、法乙升降级压力导致战意判断更复杂

### 修正规则

#### 1. 赛季初风险加倍（前5轮）
乙级联赛赛季前5轮，在以下维度额外修正：
- **平局概率上修+8-12%** — 乙级联赛赛季初阵容不稳+战术未磨合→平局概率显著高于赛季均值
- **置信度强制降一级** — ★★★降为★★，★★降为★
- **首选概率上限70%** — 乙级联赛赛季初任何方向的首选概率不得超过70%（即使模型计算>70%）

#### 2. 新赛季+乙级联赛叠加效应
当新赛季前2轮（规则35修正）与乙级联赛风险（规则57）同时触发时：
- lambda_total修正取两者较高值（不叠加，避免过度修正）

## 规则76：跨联赛等级判定——先判联赛水平，再判队伍，再分析（2026-10-14新增，用户明确要求）

> 用户原话："欧冠等跨国际比赛，和一般国内联赛不一样，应该考虑联赛水平，然后再进行判断，联赛判断前，先判断联赛等级，队伍，然后再进行分析。"

**1. 触发（强制）**
- **跨联赛赛事**（两队来自不同国内联赛：欧冠/欧联/欧协联/亚冠精英/亚冠乙/解放者杯/南美杯/世俱杯/欧国联/跨联赛杯赛）→ **先执行本规则五步判定，再进入常规联赛分析（规则22/24/34/35/66）**
- **同联赛内战**（如欧冠中曼城vs利物浦）→ 不触发，输出"同联赛，不触发规则76"

**2. 五步判定流程（联赛分析器产出结构化结果，禁止跳步）**

```
Step 1: 判赛事本身等级
        欧冠精英赛 ＞ 欧联 ≈ 欧协联 ＞ 亚冠精英 ＞ 解放者杯 ＞ 亚冠乙 ≈ 世俱杯
        → 输出赛事档（决定节奏基线/强队密度/轮换程度；欧冠档联动规则34 TTG修正）
Step 2: 判两队各自所属国内联赛的水平等级（按下表L1-L4分档，禁止临场拍脑袋）
Step 3: 判两队在其国内联赛的相对位置（榜首/争冠区/中游/保级区）
        → 位置决定"实际档次"（如荷甲卫冕冠军≈L2强队、意甲升班马≈L2中游）
        ★ 本条即"先判联赛等级，再判队伍"中的"队伍"环节
Step 4: 得出等级差先验：等级差 = |L(主队联赛) − L(客队联赛)|
        等级差≥1档 → 激活校准；≥2档 → 定义为"跨级对阵"
Step 5: 输出校准建议（提交模型引擎执行+总控走查）
        ① λ打折建议（低等级方）② 爆冷概率先验 ③ 让球盘参考 ④ 大小球倾向
```

**3. 国内联赛水平分档表（规则76专用，2026-10-14建立）**

| 档 | 定位 | 联赛 | 说明 |
|:---|:---|:---|:---|
| **L1** | 欧洲顶级 | 英超/西甲/意甲/德甲/法甲 | Big5，跨级对阵时默认实力支撑 |

**4. 校准建议细则（供模型引擎执行）**
- **λ打折（联动跨联赛xG失真）**：低等级方（L档低于对手）国内数据不可直接套用——等级差≥1档：低等级方λ×0.90-0.95；等级差≥2档（跨级对阵）：再×0.90（上限累计×0.85）
- **爆冷先验（跨联赛特有）**：跨等级对阵中低等级方主场爆冷是**系统性风险**，其爆冷概率评估不得低于"同等级内部冷门"标准；高等级方为客队时叠加空场/场地/草皮修正（规则72）
- **让球盘参考**：等级差≥2档+身价差≥2倍时，市场深盘需防"低等级方主场死守+高等级方轮换"浅赢（联动规则52a让平路径）
- **大小球**：跨级对阵倾向两极化——强队轮换磨阵地→小球；弱队防线崩盘→大球；交规则74六档落档

**5. 报告要求（强制）**
- 跨联赛场次场次卡片**联赛行**标注：`联赛等级：{赛事}({赛事档})｜{主队联赛}L{n} vs {客队联赛}L{n}（等级差{n}档，{先验结论一句话}）`
- 同联赛内战标注：`同联赛，不触发规则76`

**6. 与现有规则的边界**
- **规则34**（欧冠TTG修正）：规则76先判赛事等级，规则34的TTG修正仍适用，二者叠加
- **规则65**（大球上修Tier1/2/3）：两套分档口径——规则65服务大球上修，规则76服务跨联赛等级差判定，**互不替代**
- **规则36**（身价对比）：身价差=市场估值维度，等级差=竞争环境维度，并行使用
- **规则66**（半场平局）：杯赛仍不适用（赛制混合不做单值修正），等级差先验不影响半场平局口径
- **规则72**（空场）：空场/中立场修正独立于等级差先验，二者叠加执行
