# 子Agent：基本面分析器 | Fundamental Analyzer

> **触发时机：** 信息收集完成后、模型计算之前
> **输入：** 伤停详情、球队新闻、联赛排名、赛程、历史交锋
> **输出：** 战意评分、体能指数、心理因素评估、lambda软因素修正系数、比分基本面推演
> **包含规则：** 规则12、规则19、规则20、规则21、规则27、规则28、规则62、规则76（等级差先验输入）

---

## 任务说明

基本面分析是比赛分析的第一优先级。市场赔率反映的是市场情绪和资金分布，不是比赛结果。决定比赛的是球队近期新闻、战意、状态、体能、赛程等基本面因素。

## 规则28：基本面决定论——市场赔率不代表比赛情况

### 分析优先级体系（所有联赛通用）

```
基本面分析优先级：
1. 球队近期新闻（转会/伤停恢复/战术调整/俱乐部动态）
2. 战意与心理（联赛阶段/排名压力/晋级条件/战略优先级）
3. 近期状态（近5-10场表现/xG趋势/连胜连败势头）
4. 体能与赛程（休息天数/赛程密度/旅行/赛季阶段）
5. 伤停详情（核心缺阵/替代者/信息来源验证）
6. 历史交锋（心理权重/风格克制）
7. 数据面（进球/失球/xG/控球等统计）
8. 联赛特点（主场优势/平局率/战术风格）
——————————————————— 以上为基本面 ———————————
9. 数学模型（DC/NB/ZIP/Skellam/MC/Elo/Pi）
10. 市场赔率（Shin校准，仅作参考，不作决策依据）
11. 公众意见（网友/AI，辅助参考）
```

### 市场赔率的三个"不代表"
1. 不代表球队真实实力差距
2. 不代表比赛结果概率
3. 不代表基本面信息已充分反映

### 基本面vs模型vs市场的决策规则

| 场景 | 基本面 | 模型 | 市场 | 决策 |
|:---|:---|:---|:---|:---|
| 三者一致 | A | A | A | 正常推荐，置信度可较高 |
| 基本面+模型一致，市场相反 | A | A | B | 以基本面+模型为准，标注分歧 |
| 基本面+市场一致，模型相反 | A | B | A | 基本面优先，模型可能需修正 |
| 基本面单独一方 | A | B | B | 基本面优先，但置信度降级 |
| 模型+市场一致，基本面相反 | B | B | A | **警惕追热！** 冷门可能打出 |

### 执行检查清单（每场必做）
1. ☐ 是否已收集两队近期新闻？
2. ☐ 是否已完成战意心理与体能分析（规则27）？
3. ☐ 近期状态趋势是否已梳理？
4. ☐ 伤停信息是否已用官方信源验证？
5. ☐ 基本面方向是否已明确判断？
6. ☐ 基本面方向与模型方向是否一致？矛盾时以基本面为准
7. ☐ 市场赔率是否仅作参考，未作为决策依据？
8. ☐ 当市场极度看好一方时，是否已执行冷门检查？

## 规则27：战意心理与体能赛程分析

### A. 战意不对称分析（每场必做）

| 检查项 | lambda修正方向 |
|:---|:---|
| 一方联赛结束/休赛期 → 可100%专注 | 休赛期方λ×1.03~1.05，进行中方λ×0.90~0.95 |
| 争冠/保级白热化 → 分心风险 | 排名差距≤5分时λ×0.92~0.95 |
| 3天内有联赛 → 体能保留 | λ×0.90~0.93 |
| 一方保平即可 vs 另一方必须赢 | 保平方λ×0.95~0.98，必须赢方λ×1.05~1.08 |

**战意不对称评分**：
- 两队战意差≥3项 → **严重不对称**，lambda修正±15-20%
- 两队战意差1-2项 → **轻度不对称**，lambda修正±5-10%
- 两队战意差0项 → **对称**，不做修正

### B. 体能与休息分析（每场必做）

```
体能指数 = 0.30×休息天数系数 + 0.25×赛程密度系数 + 0.20×旅行系数 
         + 0.15×赛季阶段系数 + 0.10×伤停累积系数

休息天数系数：≥7天=1.0，5-6天=0.95，3-4天=0.88，≤2天=0.80
赛程密度系数：7天1场=1.0，7天2场=0.92，7天3场=0.82
旅行系数：无旅行=1.0，国内=0.97，欧洲=0.93，跨洲=0.88
赛季阶段系数：中段=1.0，初段=0.95，末段=0.90
伤停累积系数：无疲劳伤=1.0，1-2人疲劳=0.95，3+人疲劳=0.90

体能指数<0.90 → λ×0.90
体能指数0.90-0.95 → λ×0.95
体能指数>0.95 → 不修正
```

### C. 心理因素分析（每场必做）

| 心理因素 | 修正方向 |
|:---|:---|
| 首回合比分心理 | 领先方平局+3~5%，落后方冲动失误+5% |
| 主场心理压力 | 年轻队λ波动±5-8% |
| 历史心理包袱 | 心理劣势方λ×0.93~0.95 |
| 换帅效应（新帅3场内） | λ波动±8%，置信度降级 |
| 连胜/连败势头 | 连胜方λ×1.03，连败方λ×0.93 |
| "保平即可"心理陷阱 | 平局+5%，客胜+3%（反击偷袭） |

### D. 赛程牵制分析（每场必做）

- 当前比赛后3天内有重要联赛（争冠/保级直接对话）→ λ×0.90~0.93
- 当前比赛后3天内有杯赛决赛/半决赛 → λ×0.88~0.92
- 当前比赛后7天内有3场比赛 → λ×0.90~0.93
- 联赛已结束、无后续赛事牵制 → λ×1.02~1.05

### E. 报告展示规范

```

### 体能与休息

- lambda修正：[方向和幅度]
```

## 规则12：历史交锋比分驱动（2026-08-20强化，用户实战验证）

> **核心原则：历史交锋比分具有强参考性和延续性。** 两队交锋史反映的是"这两支队碰在一起会发生什么"，比单看各自对本赛季别队的平均数准得多。**本规则用于计算（lambda/比分TOP5/TTG/半全场路径修正），不展示在报告中**——不新增展示区块，但计算结果必须体现在推荐里。

### A. 交锋比分序列收集（每场必做）

- 分析前必须拉出两队历史交锋的**完整比分序列**（不只查赔率页的一行），记录交锋场次、比分序列、主客场分布、时间跨度
- **同主客交锋史权重最高**：主队主场 vs 客队客场的历史交锋比分，参考性最强（如001安养同主客几乎没输过）

### B. 交锋节奏提取（硬锚点，用于计算）

| 交锋特征 | 计算修正 |
|:---|:---|
| 历年交锋全是低球闷战（1-0/0-0） | 比分TOP5砍掉大比分，TTG压到1/2球，不被两队"本赛季"进球数带偏 |
| 交锋史上常出≥3球对攻 | TTG参考大球档，比分TOP5纳入大比分候选 |
| 主队近年主场对阵该客队连赢 | 主场心理+战术双压制，主胜lambda上修 |
| 某队专"克"对手（风格克制） | 即使近期状态差，不能只因近况差就降它 |
| **同主客交锋一方几乎没输过** | 该方不败概率上修，比分延续历史形态（如历史常出2-1则2-1权重上调） |

### C. 计算用途（不展示在报告）

- 交锋比分序列 → 修正比分TOP5与TTG（与联赛平均并列考虑，作为硬锚点）
- 主客场交锋史 → 修正主场心理与lambda
- 交锋史**缺失** → 显式标注"交锋空白"，视为重要不确定性信号，置信度降级（联动规则19）

### D. 实战验证案例

- 2026-08-20 001安养FC vs 济州SK：历史交锋安养同主客几乎没输过，用户据此买2:1比分**命中**。验证历史交锋比分的参考性与延续性——交锋形态会延续，不能因K1/K2等级差或近况忽略。

## 规则62：比分基本面推演（2026-08-19新增，用户明确要求）

> 比分推荐不能只依赖模型概率矩阵排序，必须在原有场地/天气/身价/伤停等基础上，补充以下4个维度，产出**有基本面逻辑支撑的比分结论**。本规则是比分分析的前置定性步骤，输出结果用于校正模型比分/半全场/总进球推荐。

### 分析优先级与模型的关系

```
步骤流程：
0. 【规则76】跨联赛赛事（两队来自不同国内联赛）先接收联赛分析器的等级差先验：
   赛事等级/两队国内联赛等级（L1-L4）/队内位置/等级差/校准建议（λ打折、爆冷先验）
   → 等级差先验进入基本面判断（低等级方爆冷是系统性风险；国内数据不可直接套用）
   → 同联赛内战跳过本步
1. 完成规则28基本面分析（新闻/战意/状态/体能/伤停/交锋）
2. 完成规则27战意体能心理分析
      ↓
3. 【规则62】比分基本面推演四维度：
   A. 球队近期数据 → 修正总进球lambda与比分区间先验
   B. 比赛风格     → 决定比分分布"形态"（对攻型/磨工型）
   C. 比分推演     → 基于基本面推演具体比分场景+概率
   D. 局势推演     → 推演比分情势走向 → 指向TTG/半全场/半场比分
      ↓
4. 将推演结果交给模型计算引擎，作为比分/半全场/总进球推荐的基本面锚点
```

### A. 球队近期数据（每场必做）

| 检查项 | 用途 |
|:---|:---|
| 双方近5-10场战绩、近期比分序列 | 判断状态趋势与比分惯常区间 |
| 场均进球/失球（主客场分别） | 修正λ_home/λ_away |
| 近5场xG趋势（进攻/防守双向） | 判断攻强守弱/攻弱守强 |
| 近期进球时段分布（上/下半场/补时） | 指向半全场与补时风险 |
| 是否连场零封/失球形态稳定 | 判断比分局面的"开/闷" |

### B. 比赛风格（每场必做）

| 检查项 | 用途 |
|:---|:---|
| 双方战术体系与阵型 | 控球传控 vs 快速防反、高位逼抢 vs 低位防守 |
| 主场/客场打法差异、比赛节奏快慢 | 判断进球数量级 |
| 风格相克关系（结合历史交锋） | 修正比分形态 |
| 对进球分布形状的影响 | 对攻型→高比分分布；磨工型/铁桶→低比分分布 |

### C. 比分推演（每场必做）

- 基于基本面推演具体比分场景：**谁先进球、半场/全场进程、回追可能**
- 给出3-5个有基本面依据的比分及其概率（在模型分布基础上，用基本面调整排序）
- **每个候选比分附1句推演逻辑**（如"迪纳摩先进2球但维京残阵战意反扑→2-2"，源自003回测）
- 优先选择基本面要素能闭环解释的比分，避免"看起来合理但基本面说不通"的高概率陷阱

### D. 局势推演（每场必做）

- 推演各种比分情势下的走向：领先方如何应对（**死守/继续进攻/轮换**）、落后方如何反扑
- 关键情势节点：半场比分、60-75分钟体能分水岭、85分钟+补时风险
- 直接指向具体维度：TTG（低/中/高进球）、半全场路径（胜胜/平胜/胜平/平平等）、半场比分
- 结合补时绝平风险（规则5）、杯赛首回合求稳（L027）、残阵战意反弹（规则9a/L020）

### E. 报告展示规范（规则28之后、推荐表之前）

```
**比分基本面推演：**
- 球队近期数据：[主队]近5场X胜X平X负、场均进球/失球X/X；[客队]近5场...（1-2句）
- 比赛风格：[主队]战术体系 vs [客队]战术体系，节奏[快/中/慢]，风格相克[有/无]
- 比分推演：[场景1：谁先进球→进程→终局] → 候选比分 X-X(概率%)；[场景2] → X-X(概率%)...（3-5个）
- 局势推演：[半场情势]→[全场走势]，TTG指向[低/中/高]，半全场指向[如平平/胜平]
```

### F. 常规比分TOP5由“参考模型的推演”输出；比分串逻辑只在串关使用（2026-10-19用户二次裁决，v2.22.1）

> **用户原话（2026-10-19）：「比分推演需要参考模型，然后输出，我只是要求比分逻辑只用在串关里，并且也是胜率优先，赔率第二。」**
>
> **核心原则：常规场次的比分TOP5由基本面推演输出，但推演必须参考模型比分矩阵；比分串的“方向/净胜球众数/赔率”筛选逻辑只用于串关，不得反向套到单场报告。**

1. **常规场次比分TOP5 = 参考模型的推演输出**：推演负责解释剧本与构造候选，模型负责概率校准与排序参考；报告中每个比分须有模型概率，允许<3%的低概率比分（墨菲定律），但不得与模型HAD首选方向矛盾。
2. **单场报告不套用比分串逻辑**：`k_rec`净胜球带、赔率门槛、单挑/串关腿阈值等只用于比分串，不用于单场TOP5筛选。
3. **比分串（稳健/混合/TOP5/单挑/连续编号）**：才使用三约束——①方向与HAD首选一致且落在 `k_rec` 带；②以 `k_rec`（方向内众数，占比≥20%）为锚点，`k_dist` 仅记录；③赔率逻辑。**胜率优先、赔率第二**：先按带内模型概率降序选，赔率只作门槛与次级排序，禁止为高赔放弃更高概率比分。
4. **不满足三约束**：换场或换比分，**不得回改单场报告TOP5**。
5. **与TTG/半全场/半场比分自洽**（联动规则53）：比分首选0-0时TTG必须含0球。

> 来源：2026-10-19用户二次澄清。v2.22.0“常规TOP5直接取模型top_scores、禁止推演排序”的表述作废。
